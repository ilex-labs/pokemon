# Pokémon tools

Planners for the parts of the games that aren't explained well — egg
inheritance, hatch efficiency, postgame progress.

Live at **[ilex-labs.com/pokemon](https://ilex-labs.com/pokemon/)**

## What's here

- **Daycare Planner** (`/daycare`) — a step-by-step plan for a target
  spread, with the inheritance rules that apply in your specific game
  flagged at the step where they bite
- **Postgame Checklist** (`/postgame`) — what's left, scoped to the game
  and how far you've got

Most calculators give you odds. These give you the order of operations,
and explain the mechanics the games leave you to work out yourself.

## Data

Everything is cross-verified against at least two independent sources
before it ships, and nothing is copied wholesale from any one site.
Descriptions are written from scratch. Where a value can't be verified,
it's left out rather than guessed.
